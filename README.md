⚡ Electric Vehicle Market Performance & Insights

📌 Project Overview

The Electric Vehicle Market Performance & Insights project analyses electric vehicle market data using Tableau. It presents important information through interactive visualisations and a dashboard to help users understand EV market performance.

🎯 Project Objectives

- Analyse electric vehicle market performance.
- Compare sales across EV categories and manufacturers.
- Explore battery capacity and driving range.
- Understand customer ratings and satisfaction.
- Examine battery technology and manufacturing countries.

🛠️ Tools & Technologies

- Tableau – Data visualisation and dashboard creation
- CSV – Dataset
- GitHub – Project documentation and file hosting

📊 Key Visualisations

The project includes nine visualisations:

1. Sales by Category
2. Battery Capacity by Category
3. Customer Ratings by Category
4. Driving Range by Category
5. Top Manufacturers by Sales
6. Customer Satisfaction by Manufacturer
7. Battery Technology Distribution
8. Manufacturer Sales Performance
9. Sales by Manufacturing Country
